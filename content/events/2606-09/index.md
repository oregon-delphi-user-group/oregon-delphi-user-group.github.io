**Homer Jones** will discuss Code Signing Certificate types including **Individual Validation** (IV), **Organization Validation** (OV), and **Extended Validation** (EV). Information on the evolution of certificate security will be touched on as well as the advantages of automatic signing versus manual. The presentation will include an INNO Setup script and a Delphi app that signs user selected applications.

**David Cornelius** will follow with information about a product that allows a locally installed hardware key to be used from multiple locations in a code-signing process.
